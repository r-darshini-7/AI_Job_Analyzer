# AI Job Analyzer 🛡️

A Machine Learning web application built to protect job seekers from fake online job postings. Users can paste a job description into the website, and our AI instantly predicts whether it is a real opportunity or a scam.

## ✨ Key Features
* **Instant AI Scanning:** Analyzes job descriptions in real-time.
* **Visual Results:** Displays the "Real vs. Fake" probability using interactive Pie and Bar charts.
* **Analytics Dashboard:** Tracks daily, monthly, and yearly scam trends.

## 💻 Tech Stack
* **Backend & AI:** Python, Flask, Scikit-Learn
* **Frontend:** HTML, Tailwind CSS, JavaScript, Chart.js

## ⚙️ How to Run This Project
Since the trained AI model is too large for GitHub, you just need to generate it on your computer first!

1. Download or clone this code to your computer.
2. Open your terminal and run `python train_model.py` (This trains the AI and creates the model file).
3. Once that finishes, run `python Backend.py` to start the website.
4. Open the link provided in your terminal (usually `http://127.0.0.1:5000`) in your web browser.
